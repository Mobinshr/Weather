# آب‌وهوای قندیل

برنامهٔ اندرویدی آب‌وهوای قندیل با جست‌وجوی جهانی شهرها، GPS، پیش‌بینی ساعتی و هفت‌روزه و هشدار بارش.

## امکانات نسخهٔ 3.5.1
- آیکون اختصاصی تصویر آفتاب، ابر و دمای ۲۴ درجه مطابق فایل تازهٔ ارسالی.
- رابط بازطراحی‌شده بر اساس فایل HTML ارائه‌شده، با نمودارها و نمایش جزئیات بیشتر.
- کش معتبر با عمر ۲۴ ساعته، تازه‌سازی ۱۵ دقیقه‌ای و سقف ۱۲ شهر ذخیره‌شده.
- لغو درخواست شهر قبلی هنگام انتخاب شهر جدید و جلوگیری از نمایش پاسخ‌های دیررس.
- اصلاح تداخل CSS منوی شناور جست‌وجوی شهرها.
- جست‌وجوی جهانی شهرها به فارسی و انگلیسی با کشوی شناور و قابل اسکرول، نمایش حداکثر ۱۰۰ نتیجه و انتخاب مستقیم شهر؛ رابط برنامه فارسی باقی می‌ماند.
- دریافت وضعیت آب‌وهوا با GPS.
- تشخیص خودکار زبان سیستم؛ ترجمهٔ داخلی فارسی، انگلیسی و عربی و ترجمهٔ آنلاین برای زبان‌های دیگر.
- تغییر خودکار جهت رابط کاربری و قالب تاریخ و اعداد بر اساس زبان دستگاه.
- نمایش احتمال بارش در ساعت‌های آینده و روزهای هفته، به‌همراه مقدار بارش به میلی‌متر.
- هشدار بارش از طریق اعلان بومی اندروید؛ برای دریافت آن باید مجوز اعلان فعال باشد.

ساخت APK از طریق GitHub Actions انجام می‌شود.
