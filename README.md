# آب‌وهوای قندیل

نسخهٔ Native اندرویدی قندیل با Kotlin و Jetpack Compose؛ طراحی و امکانات صفحهٔ قبلی حفظ شده‌اند.

## امکانات نسخهٔ 3.6.5
- رابط Native با پس‌زمینهٔ پویا بر اساس وضعیت هوا و شب/روز.
- جست‌وجوی شهرها به فارسی و انگلیسی و تعیین موقعیت با GPS.
- نمایش دمای فعلی، وضعیت هوا، بیشینه و کمینهٔ روز.
- نمودار دمای ۲۴ ساعت آینده و نمودار احتمال بارش ۲۴ ساعت آینده.
- پیش‌بینی ساعتی و هفت‌روزه با نوار بازهٔ دمای کمینه تا بیشینه.
- کارت‌های جزئیات UV، طلوع و غروب، سرعت باد، حس واقعی، رطوبت، احتمال بارش، کیفیت هوا و فشار هوا.
- هشدار بارش برای شش ساعت آینده و احتمال بارش بالای ۷۰٪ در همان روز.
- اعلان بومی اندروید، وضعیت آنلاین/آفلاین، شمارش معکوس تازه‌سازی ۱۵ دقیقه‌ای.
- کش محلی با عمر ۲۴ ساعته، تازه‌سازی ۱۵ دقیقه‌ای و سقف ۱۲ شهر ذخیره‌شده.
- حفظ شهر آخرین انتخاب‌شده و نمایش داده‌های ذخیره‌شده هنگام قطع اینترنت.
- ثبت خطاهای بسته‌شدن ناگهانی و نمایش گزارش قابل کپی در اجرای بعدی.
- امضای نهایی APK با V1 و V2 از طریق apksigner؛ بررسی اجباری هر دو امضا در CI.

ساخت و انتشار APK از طریق GitHub Actions انجام می‌شود.

## عیب‌یابی
اگر برنامه ناگهان بسته شود، خطای فنی به‌صورت محلی روی گوشی ثبت می‌شود. در اجرای بعدی، پیش از بازشدن صفحهٔ اصلی، گزینهٔ «کپی گزارش و خروج» نمایش داده می‌شود. گزارش شامل نسخهٔ برنامه، مدل دستگاه، نسخهٔ اندروید و Stack Trace خطاست؛ آن را برای بررسی ارسال کنید.

**توجه:** نسخه‌های 3.6.2 و 3.6.3 را به‌دلیل مشکل امضای V1 نصب نکنید؛ از نسخهٔ 3.6.5 استفاده کنید.
